# Sleep Health Analysis with Machine Learning in R

Analysis of the **Sleep Health and Lifestyle Dataset** using classical multivariate statistics and machine learning techniques implemented in **R**.

This project was developed as part of the *Intelligent Data Analysis* course and explores both supervised and unsupervised learning methods to identify patterns associated with sleep disorders.

---

## Dataset

- **Dataset:** Sleep Health and Lifestyle Dataset
- **Source:** Laksika Tharmalingam (modified from a Google dataset)
- **Publication year:** 2023

The analysis was performed on a **stratified random sample (n = 300)** based on the *Sleep Disorder* variable.

---

## Project Workflow

### Data preprocessing

- Stratified random sampling
- Feature engineering:
  - Split **Blood Pressure** into:
    - Systolic Pressure
    - Diastolic Pressure
- Data cleaning and preparation

---

## Methods

### Unsupervised Learning

- Principal Component Analysis (PCA)
- Simple Correspondence Analysis (CA)
- Multiple Correspondence Analysis (MCA)
- K-Means Clustering

### Supervised Learning

- Linear Discriminant Analysis (LDA)
- Support Vector Machines (SVM)
- K-Nearest Neighbors (K-NN)
